## Executive summary

**Go** — on Solution 1 (Screenshot Drop) immediately, because it is the only solution with zero open discovery questions, confirmed infrastructure, and an unambiguous evidence base covering the highest-frequency unmet need in both developer and designer research.

**Recommended solution:** **Solution 1 — Screenshot Drop**, followed by Solution 6 (Live URL Inspection, 6a sub-mode) in the same sprint pending one reachability test, and Solution 4 (Annotation Anchor) in the second sprint after designer adoption is validated. Solution 1 delivers the core C4 capability — a Carbon-aware visual diff between a Figma frame and a live implementation — using only infrastructure already available in the Bob environment (Figma MCP `get_screenshot`, Claude vision, Carbon MCP `docs_search`). 3. **EG3 — `get_design_context` output quality on Figma files without Code Connect:** Determines the quality floor for Solution 4 on low-maturity teams (Hariharan's Angular team). Requires one test run on a real low-maturity Figma file.

## Opportunity

IBM product teams designing and building on Carbon have no tool to objectively compare a finished or in-progress implementation against its Figma source of truth with Carbon-aware interpretation of the gap. The current practice — manual side-by-side review, informal video annotations, 2-hour designer annotation sessions — is slow, subjective, catches only visually obvious drift, and misses token-level violations entirely. Designers across all three research teams (Integration, B2B, API Management) described discovering significant implementation drift only after implementation was complete, requiring rework cycles that consumed days of combined designer-developer time. No tool in the current market closes this gap: every surveyed competitor (FigmaLint, Chromatic, Applitools, Tokens Studio, Zeroheight, Supernova) operates on one side of the Figma/code boundary — none perform a cross-boundary, Carbon-interpreted delta. C4 is the gap with the broadest research evidence, the deepest competitive whitespace, and the lowest technical build risk of the five customer opportunities identified in discovery.
