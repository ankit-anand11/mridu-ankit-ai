04 / 09 What we heard · 6 people · 4 webMethods teams

Three failures invisible to today's review process

Invisible

Tokens are never verified

A screen can look right while the code uses #0f62fe instead of $interactive-01. Visual review never catches this. Spacing gets hard-coded as px by default.

Silent

Non-Carbon components slip in

Bob reuses legacy components from the codebase without warning. Angular teams approximate Carbon visually with PrimeNG. Neither surfaces without a dedicated check.

Too late

Review happens after merge

Compliance is caught in QA demos — or not at all. The one team with a formal pre-merge gate has zero violations. That is not a coincidence.

"I can get the branch, put it in the tool, run it myself, generate the report,
create the ticket, assign it back to them."

— Tech Lead, webMethods API — describing what he wanted

07 / 09 Live output · the report

Every finding has a severity, a Carbon reference, and a fix

Critical

Custom dropdown — no Carbon equivalent used

Replace with <Dropdown> from @carbon/react. Border uses #8d8d8d — should be $border-subtle-01.

Major

Hardcoded spacing: 20px

Gap between cards is 20px. Carbon standard: $spacing-05 (16px). Theme-switch will break this silently.

Minor

Table row hover — wrong token

Background is #e8e8e8. Carbon standard: $layer-hover-01.

— Design-to-implementation delta — Figma: Blue-60 primary button Dev: Blue-70 ← wrong token Figma: 48px header height Dev: 56px ← $spacing-05 missing Figma: Carbon Tag component Dev: Custom pill ← non-Carbon

What Bob offers next

[B] Export report as downloadable HTML
[C] Show code fix for any finding

09 / 09 The vision

Carbon compliance should not depend on who you happen to have on your team. It should be everyone's superpower.

For designers

Run a Carbon check on your Figma frame before you hand anything to a developer. Catch the gaps before the rework clock starts.

For developers

Run it before the PR. Get the findings. Ask Bob to fix them. Merge knowing the code is compliant — no culture change required.

For the whole team

The report is the shared record. One source of truth. Every sprint. Every release. Everyone sees the same standard — and knows exactly where they stand.
