How to use this brief
  1. Paste both screenshots into your annotation tool (Figma frame, CleanShot X, or tldraw canvas)
  2. For each row: draw a box or arrow pointing to the Target region
  3. Apply the Colour shown — red = Critical, orange = Major, grey = Minor
  4. Write the Callout label as the annotation text exactly as shown
  5. Use the Arrow direction hint to position the label outside the UI, pointing inward

Figma annotation tips
• Use sticky notes (S key) for callout labels — set fill to the severity colour, text to white
• Use connector arrows (Shift+C) from the sticky to the target region
• Group each finding as: box outline on the target + arrow + sticky label
• Add a legend frame in the corner: 🔴 Critical   🟠 Major   ⬜ Minor   🟢 Correct

tldraw tips
• Paste screenshots → lock them (right-click → lock)
• Use the arrow tool to draw from labels to targets
• Double-click any shape to type the callout text directly

CleanShot X tips
• Use numbered callout circles for F2, F3… then a legend below each screenshot
• Export as PNG, paste into your presentation deck
